# bone-front
Bone Front: A modular front-end template and ruleset for building clean, animated Arabic and English web interfaces.

## Front-end skill

Use the [Clean Code, Clean Architecture, and Responsive UI skill](.github/skills/clean-code-clean-architecture-responsive/SKILL.md) when building or changing website interfaces. It defines the expected Arabic/English and RTL/LTR support, accessible light/dark theme behavior, logo-led brand styling, and responsive implementation practices.
